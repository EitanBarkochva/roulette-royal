# 🎰 רולטה רויאל — Roulette Royal

אפליקציית קזינו רולטה משחקית בקובץ HTML יחיד. נפתחת בכל דפדפן, ללא התקנה.

## 🎮 איך משחקים
- בוחרים ערך ז'יטון (1 / 5 / 25 / 100 / 500) ולוחצים על הלוח כדי להניח הימור.
- אפשר להמר על מספר בודד (35:1), צבע / זוגי-אי-זוגי / חצאים (1:1), תריסר / טור (2:1).
- לוחצים **"סובב!"** — הגלגל מסתובב, הכדור נוחת, והזכיות מחושבות אוטומטית.

## 💰 ז'יטונים
- היתרה נשמרת בדפדפן (localStorage) — מתחילים עם 1,000 ז'יטונים.
- חנות ז'יטונים זמינה תמיד, ונפתחת אוטומטית כשנגמרים. **השער: 100 ז'יטונים = 1 ₪.**

> ⚠️ אפליקציית הדגמה למשחק בלבד. אין תשלום אמיתי — ה"רכישה" וירטואלית והז'יטונים חסרי ערך כספי.

## קבצים
- `index.html` — אפליקציית הקזינו (הראשית)
- `casino-roulette-3d.html` — שולחן רולטה בתלת-ממד (תצוגה)
